# Roadmap

## Current product

Astro Static Studio is a local-first editor and static Astro renderer. It includes a loopback API, content contracts, media handling, local backups, and a Cloudflare Pages preview publishing path. The public source tree contains an empty, neutral content fixture; customer site repositories and content are separate.

## Remaining validation

- Complete browser acceptance for V1 backup recovery, V1-to-V2 migration, and Pages/Collections editing.
- Run a task-based usability session with a non-technical desktop owner.
- Verify the Android workflow and full Astro build feasibility on a real device before describing Android as supported.
- Prepare a reviewed site scaffold as a separate GitHub template. Generate private customer repositories from it; do not use the public CMS source repository as the customer site template.
- Validate production publishing and rollback before making production-readiness claims.

These are open acceptance steps, not promises that the capabilities are complete.
